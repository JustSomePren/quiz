# Učící kvíz — Leadership & management

Adaptivní učící kvíz (ABCD): 115 otázek se správnými odpověďmi, míchání odpovědí při každém zobrazení, varianty znění otázek a výběr otázek podle tvých předchozích výsledků (slabé otázky se vracejí častěji). Pokrok se ukládá lokálně v prohlížeči.

**Spustit:** otevři `index.html` (nebo běžící GitHub Pages odkaz v popisu repozitáře).

- Režimy: Adaptivní učení / Celý test / Slabé otázky
- Ovládání: kliknutí nebo klávesy 1–6, Enter = další otázka
- `otazky.json` = editovatelná databáze otázek (text, možnosti, správný index, varianty znění)
